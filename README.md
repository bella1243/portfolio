# 
Abel's Portfolio

A portfolio website built with React, Tailwind CSS, and Framer Motion.

## Features

- Dark/Light mode toggle
- Animated particle background with network connections
- Custom cursor effects (desktop)
- Scroll progress indicator & back-to-top button
- Interactive skill cards with progress bars
- Animated experience timeline
- Project showcase with hover effects
- Contact form
- Fully responsive design
- SEO optimized
- Accessibility features

## Tech Stack

- **React ** + **TypeScript**
- **Vite** for fast development
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **Lucide React** for icons

## Getting Started

```bash
npm install
npm run dev
```
